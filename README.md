# EduHub

A beginner-friendly education resource web application for:

- 10th Class
- Intermediate
- B.Tech
- Notes
- YouTube learning resources
- Previous Year Questions (PYQs)
- Live classes

## Run

No backend is required for this starter version.

1. Open `index.html` in a browser.
2. Edit `js/app.js` to add your own notes, YouTube links, PYQs and live-class links.

## Recommended next version

For a real production application, add:

- Student login/signup
- Admin dashboard
- Database (MySQL/PostgreSQL/MongoDB)
- PDF upload for notes and PYQs
- Subject/chapter/year filters
- YouTube video embedding
- Live class links
- Favorites/bookmarks
- Search
- Admin approval for submitted resources
- Cloud storage
